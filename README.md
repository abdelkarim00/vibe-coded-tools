# Vibe Coded Tools

A collection of small, practical, locally-runnable tools.

## Tools

- **[local-tts](./apps/local-tts)** — A free, 100% local Text-to-Speech (TTS) service powered by [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) and ONNX Runtime. Includes a web studio UI, a CLI, and an OpenAI-compatible `/v1/audio/speech` API. Runs on CPU (including Intel Macs).
